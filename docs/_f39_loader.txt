 Loader & Unloader Process Checklist 
 System Setup & Report Overview 
 ●  [ ] Introduce a new section of Loader & Unloader (Located in the Procurement section). 
 ●  [ ] This is a system-generated report. 
 ●  [ ] Ensure daily records capture which unloader unloaded which truck and at what time. 
 ●  [ ] Maintain independent daily details for each individual unloader. 
 Entry & Linkage 
 ●  [ ] Link truck entry to the supervisor-selected unloader upon Paddy inward entry. 
 ●  [ ] Major unload data is fetched from Paddy Inward details. 
 ●  [ ] Record the number of bags unloaded by Unloader 1 (and Unloader 2 if part stack). 
 Time Tracking Sequence & Rules 
 ●  [ ] Maintain chronological sequence for time entries: 
 1.  Paddy Inward (In Time) 
 2.  Unloader Allotment (Unload Start Time) 
 3.  Unloader Finish (Unload Finish Time) 
 4.  Net Weight Paddy Inward (Out Time) 
 ●  [ ] Case: Ensure Unloader Finish time is  not  before  Paddy Inward (In Time) or Unload 
 Start Time. 
 Time Gap Maintenance guideline 
 ●  [ ] As mentioned, this much time gap should be maintained. 
 ●  [ ] Paddy Inward - Unloader Allotment:  Min 5 minutes 
 ●  [ ] Unloader Allotment - Unloader Finish Time:  Min  30 minutes 
 ●  [ ] Unloader Finish Time - Paddy Inward Net Weight:  Min 5 minutes 
 Reporting & Display Requirements 
 ●  [ ] Exclude incomplete unload entries from the unloader main list. 
 ●  [ ] Display only trucks whose unloading details and net weight Paddy inward entry out 
 time have been recorded to maintain harmony between Unloaded Data and Paddy Inward 
 Data. 
 Unloading Management Checklist 
 Vehicle Entry & Hold Rules 
 ●  [ ] This is a mill-wise report. 
 ●  [ ] During one truck unloading, he cannot unload any other truck. Prevent duplicate entries 
 for the vehicle while processing. 
 ●  [ ] Provide a "Hold" option Tick box (with a hold reason) under Unloading Management 
 (Section 4). 
 ●  [ ] Ensure a notification pop-up asks for confirmation when selecting "Hold". 
 ●  [ ] Display entries marked as "Hold" under  Pending  Draft  in Paddy Inward. 
 ●  [ ] Allow the unloader to proceed with unloading another truck if a truck is placed on 
 "Hold". 
 Serial Number & Unloader Count Tracking 
 ●  [ ] Generate the Unloader truck count serial number only after the Paddy Inward entry is 
 submitted by the supervisor (once the Net Weight Paddy Inward entry is completed). 
 ●  [ ] Do not generate, the unloader truck count no. during active unloading. 
 ●  [ ] Credit the truck count to the unloader only when the Net Weight Paddy Inward entry is 
 submitted/completed.

 Hold & Unloader Management Rules 
 ●  [ ] Unloader cannot be changed once "Hold" is marked. 
 ●  [ ] Note that marked "Hold" entries are permanent and do not require deselection. 
 ●  [ ] Complete hold entries by selecting them from  Draft  Entries  . 
 Paddy Inward & Unloading Reports 
 ●  [ ] Net Weight Paddy Inward entries (completed entries) appear on the Paddy Inward 
 report for that day only. 
 ●  [ ] Confirm unloading entries are visible in the  Unloader  List of that Unloader  on that 
 day. 
 ●  [ ] Maintain strict chronological order for all entries. 
 Submission & Supervisor Process 
 ●  [ ] This need to be done before Paddy Inward report submission. 
 ●  [ ] Verify both the Unloader and Supervisor signatures are punched on the report prior to 
 submission. 
 ●  [ ] Ensure separate reports are completed and submitted to Admin for each individual 
 unloader. 
 ●  [ ] Exclude any vehicles remaining for unloading from that day's unloading list count. 
 Daily Report Details 
 ●  [ ] View Daily Report details organized by unloader (where each unloader report set is 
 available). 
 ●  [ ] Print all unloader reports together if desired. 
 Date Range Wise Format 
 ●  [ ] Generate Date Range wise reports for all unloader sets. 
 ●  [ ] Download or print date range wise reports for all unloaders. 
 Specific Unloader Type / Date Range 
 ●  [ ] Generate a Date Range format for a specific unloader type. 
 ●  [ ] Print all reports for a specific unloader in one go.
